# Legal and compliance placeholders

These files are drafting inputs only. They are not legal advice, approved terms,
or production-ready notices. Qualified counsel must identify the contracting
entity, applicable laws, jurisdictions, customer model, subprocessors, data flows,
and required consent/notice mechanics before approving versioned replacements.

The matching frontend pages intentionally display an unapproved-draft banner and
do not request or persist acceptance. If counsel requires acceptance, implement a
backend-authoritative document version, user/company identity, UTC timestamp,
source, and immutable audit record before adding any checkbox.

Use `legal-review-checklist.md` as the release gate.
